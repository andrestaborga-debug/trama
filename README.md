# TRAMA · Taller de Pensamiento Complejo

Un taller asincrónico y autoguiado de 24 sesiones para profesionales, inspirado en la obra de Edgar Morin.

> *Aprender a pensar lo entrelazado.*

## Sobre el taller

TRAMA es un recorrido en 6 módulos × 4 sesiones, diseñado para 30 minutos por sesión, dos veces por semana, durante 12 semanas. No hay facilitador en vivo: el método mismo conduce.

- **Módulo I** — Fundamentos: la crisis del paradigma simplificador
- **Módulo II** — Los principios del pensamiento complejo
- **Módulo III** — Sistemas, emergencia y auto-organización
- **Módulo IV** — Los saberes necesarios
- **Módulo V** — Aplicar la complejidad
- **Módulo VI** — Reforma del pensamiento y praxis

## Estructura del proyecto

```
TRAMA/

├── js/

    ├── bucles.html              # Constructor de bucles recursivos
    ├── mapa-sistemico.html      # Mapa sistémico
    ├── cegueras.html            # Brújula de cegueras
    ├── preguntas.html           # Generador de preguntas complejas
    ├── mapa-personal.html       # Mapa personal de complejidad

```

## Características

- **Bilingüe** ES/EN con toggle persistente
- **Autosave** de respuestas y progreso en `localStorage` (sin servidor)
- **Sin dependencias** de build — HTML/CSS/JS puro
- **Responsive** (móvil, tablet, escritorio)
- **Imprimible** — hojas con estilo print-friendly
- **Exportable** — Markdown / JSON desde cada herramienta

## Uso

1. Abre `index.html` en cualquier navegador moderno
2. Recorre las sesiones a tu ritmo
3. Tu progreso queda guardado en tu navegador
